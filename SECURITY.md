# Security Policy

Private vulnerability reporting is not currently enabled for this repository. Contact the verified maintainer @ChandanrajM through a private channel; do not publish exploit details in an issue.

The backend handles telemetry, tokens, alerts, incidents, notification URLs, and database credentials. Include commit, affected endpoint, reproduction steps, and sanitized evidence. Production operators must enable authentication, restrict CORS, use TLS, protect credentials, and control notification egress.
